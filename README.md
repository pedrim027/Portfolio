# Portfólio - Pedro Peixoto Carvalho

Portfólio profissional de Produção Multimídia, Modelagem 3D e Ilustração Digital desenvolvido com interface moderna em tema dark e acentos em ciano neon.

## 🚀 Estrutura de Páginas

- **`index.html`**: Versão principal completa e totalmente responsiva (Desktop e Mobile com menu hambúrguer interativo).
- **`desktop.html`**: Cópia dedicada para visualização desktop em telas amplas.
- **`mobile.html`** (e `portatil.html`): Versão portátil dedicada para smartphones com barra de navegação inferior (*Bottom App Bar*) e gaveta deslizante (*Bottom Sheet Modal*).

## 🛠️ Tecnologias e Recursos

- **HTML5 Semântico**: Estruturação acessível com descrições `alt` ricas para todas as imagens.
- **Tailwind CSS v3**: Estilização moderna e responsiva via CDN oficial.
- **Google Fonts**: Tipografia com *Space Grotesk* (títulos) e *Inter* (corpo de texto).
- **Vercel Standards**: Configurado com `vercel.json` para URLs limpas (`cleanUrls: true`), rotas diretas (`/`, `/desktop`, `/mobile`, `/portatil`) e cabeçalhos de segurança (*Security Headers*).

## 🌐 Deploy na Vercel

O projeto está 100% pronto para deploy na Vercel com zero-configuração necessária:

1. **Importação via GitHub:**
   - Faça o push deste repositório no seu GitHub.
   - Acesse o painel da Vercel ([vercel.com](https://vercel.com)).
   - Clique em **"Add New Project"** &rarr; Selecione o repositório no GitHub.
   - O framework será automaticamente identificado como *Other (Static)*.
   - Clique em **"Deploy"**.

2. **Rotas Disponíveis após o Deploy:**
   - `/` &rarr; Página principal responsiva (`index.html`)
   - `/desktop` &rarr; Versão Desktop dedicada (`desktop.html`)
   - `/mobile` &rarr; Versão Portátil com Bottom Bar (`mobile.html`)
